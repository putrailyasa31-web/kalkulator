# Kalkulator Python

Kalkulator berbasis terminal dengan riwayat hitung otomatis.

## Fitur
- Operasi + - * / // % ** dan tanda kurung
- Fungsi sqrt, sin, cos, tan, log, ln, abs, round, fak
- Konstanta pi, e, dan ans (hasil terakhir)
- Riwayat tersimpan di riwayat.json

## Cara menjalankan
python kalkulator.py
